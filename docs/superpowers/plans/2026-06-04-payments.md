## Flow Summary

**User pays:**
1. User picks date → `POST /sessions` → Session{status:pending}
2. CheckoutModal → `POST /sessions/:id/checkout` → PaymentIntent created
3. Stripe.confirmPayment() → card charged
4. Webhook `payment_intent.succeeded` → Session{status:paid}
5. Professional receives 50% automatically via `transfer_data.destination`

**Professional connects Stripe:**
1. Dashboard "Pagos" tab → "Conectar cuenta Stripe" button
2. `POST /professionals/me/stripe/connect` → Express account created + onboarding link
3. Redirect to Stripe → KYC completed
4. Stripe → `/dashboard/professional/stripe/return?success=true`
5. `GET /professionals/me/stripe/status` → shows active state
